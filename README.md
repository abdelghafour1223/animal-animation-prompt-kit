# Animal Animation Prompt Kit

جوج برومبتات جاهزة للنسخ: ورقة الشخصية (Character Sheet) ثم فيديو عمودي 9:16.

## التشغيل محليا

افتح `index.html` مباشرة في المتصفح. لا يحتاج build ولا dependencies.

## النشر على Vercel

1. ادفع هذا المجلد إلى GitHub على `main`.
2. في Vercel اختر Add New Project ثم استورد الريبو.
3. اترك الإعدادات الافتراضية (Static، لا Build Command).
4. Deploy.

## البنية

- `index.html` — الصفحة كاملة (HTML + CSS + JS) والبرومبتات محفوظة حرفيا.
- `vercel.json` — إعدادات URLs نظيفة.
